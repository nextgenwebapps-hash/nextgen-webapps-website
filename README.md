# NEXTGEN WEB&APPS — one-page website

A responsive, single-page static website. It uses plain HTML and CSS, so there is no build step or paid hosting requirement.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Before publishing
- Replace the temporary Facebook, Instagram, X, GitHub, Google Play and App Store destinations with your official profile/app URLs.
- Add the D-U-N-S number after it is issued. Do not publish private IDs, bank details, personal documents or information that is not needed publicly.
- Confirm the public contact email is correct.
- Add a real Privacy Policy and Terms page/URL for each app as required. This landing-page summary is not a substitute for an app-specific privacy policy.
- Check current Google Play Developer Program Policies and Apple App Review Guidelines before every app submission. Requirements depend on the app's features, data practices, audience and region.

## Publish with GitHub Pages
1. Sign in at https://github.com/ and create a new repository, for example `nextgen-webapps-website`.
2. Choose **Public** (or confirm your plan supports Pages for a private repository), then create the repository.
3. Upload `index.html` and `README.md` from this folder to the repository root. The file must be named exactly `index.html`.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. GitHub Pages will show your live website URL, usually:
   `https://YOUR-GITHUB-USERNAME.github.io/nextgen-webapps-website/`
8. Open the URL and test it on mobile and desktop. Any future commit/push to the selected branch will update the site.
